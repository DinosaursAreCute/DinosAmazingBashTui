### `tui.layer.toggle`

```bash
tui.layer.toggle ID
```

Shows a hidden layer or hides a visible layer.

**Parameters**

- `ID` - layer id.

**Notes**

- A convenience function that calls [`tui.layer.show`](tui.layer.show.md) if the layer is hidden or [`tui.layer.hide`](tui.layer.hide.md) if it is visible.

**See also:** [`tui.layer.show`](tui.layer.show.md), [`tui.layer.hide`](tui.layer.hide.md)
