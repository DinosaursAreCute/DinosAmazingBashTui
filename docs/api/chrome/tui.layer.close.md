### `tui.layer.close`

```bash
tui.layer.close ID
```

Alias for [`tui.layer.hide`](tui.layer.hide.md). Hides a visible layer.

**Parameters**

- `ID` - layer id.

**Returns:** `1` when the layer is not visible.

**See also:** [`tui.layer.hide`](tui.layer.hide.md), [`tui.layer.show`](tui.layer.show.md)
