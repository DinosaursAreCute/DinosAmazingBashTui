### `tui.page.reset_field`

```bash
tui.page.reset_field ID
```

Puts one kept widget or pane back to its first-build state.

**Parameters**

- `ID`: a widget or pane the page keeps state for.

**Returns:** `1` when the page keeps nothing for `ID`.

**See also:** [`tui.page.reset`](/api/core/tui.page.reset.html)
