how to read: done = ms from the input to the LAST visible change of the screen; it is the number compared. ready = when the expected text first showed. paints = visible screen changes; CPU = app process tree incl. reaped children; written = bytes the app sent to the terminal. statistics: one value per round (median of that round's samples); [lo–hi] = bootstrap 95% CI of the median across rounds; "vs" ratios are medians of other/base with a bootstrap CI. "≈ same" = gap below the noise floor or < 5%; "unclear" = CI spans 1. flags: ~ noisy (CV > 25%) ° outlier rounds present (kept, never dropped) k/n ok = rounds where the expected text appeared stale! = expectation was already true before the input method: fresh process + HOME per round, warm-up rounds discarded, apps interleaved in shuffled order, pinned CPUs, output stamped when read and replayed offline into a terminal emulator (synchronized updates honoured), terminal answers capability queries like a modern terminal. keys: input arrives at human speed.
