### `tui.md.mono`

```bash
tui.md.mono on|off
```

Switches the style table to attributes only (bold, underline, reverse, dim, no colors) with `on`, or back to the colored table with `off`.

**Parameters**

- `on|off`: the mode to select.

**Notes**

- Switching resets the overrides made with [`tui.md.style_set`](/api/markdown/tui.md.style_set.html).
