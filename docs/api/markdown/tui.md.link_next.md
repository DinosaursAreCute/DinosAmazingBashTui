### `tui.md.link_next`

```bash
tui.md.link_next PANE
```

Focuses the next link of the document shown in `PANE`, wrapping at the end.

**Notes**

- The document is re-rendered with the focus style (class `link_focus`) and the view scrolls to the link.

**Example**

```bash
tui.md.link_next docs
```
