### `tui.pane_title_pos`

```bash
tui.pane_title_pos PANE POS
```

Sets which border line carries a pane's title.

**Parameters**

- `PANE` - pane id.
- `POS` - enum (top|bottom), default top.

**Notes**

- Markup: `title_pos="bottom"`. An invalid value is ignored with a warning.

**See also:** [`tui.pane_border`](/api/core/tui.pane_border.html)
