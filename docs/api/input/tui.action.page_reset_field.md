### `tui.action.page_reset_field`

```bash
tui.action.page_reset_field
```

Resets the focused widget, else the nearest pane around the focus that keeps state.

**Returns:** `1` when nothing around the focus keeps state.

**Notes**

- Palette command: Reset field.

**See also:** [`tui.page.reset_field`](/api/core/tui.page.reset_field.html)
