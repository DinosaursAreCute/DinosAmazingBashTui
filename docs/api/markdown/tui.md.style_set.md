### `tui.md.style_set`

```bash
tui.md.style_set CLASS SGR
```

Replaces the SGR sequence of one style class.

**Parameters**

- `CLASS`: one of `h1` `h2` `h3` `h4` `h5` `h6` `strong` `em` `code` `codeblock` `quote` `bullet` `link` `hr` `marker`.
- `SGR`: a full escape sequence such as `$'\e[1;31m'`.

**See also:** [`tui.md.mono`](/api/markdown/tui.md.mono.html)
