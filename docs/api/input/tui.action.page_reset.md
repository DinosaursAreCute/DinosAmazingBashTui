### `tui.action.page_reset`

```bash
tui.action.page_reset
```

Resets the current page to its first-build state (default key `alt+shift+r`).

**Notes**

- See [`tui.page.reset`](/api/core/tui.page.reset.html). Palette command: Reset page.

**See also:** [`tui.page.reset`](/api/core/tui.page.reset.html)
