### `tui.action.md_keys`

```bash
tui.action.md_keys
```

Opens a scrollable list of the Markdown reading commands (links, back, search, outline, folds, copy) with the keys bound to them right now: the defaults and the app's own binds. A command without a key shows `-`. Bound to `f2` by default, and listed in the command palette as "Help: Markdown reading keybinds".
