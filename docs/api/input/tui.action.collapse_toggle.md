### `tui.action.collapse_toggle`

```bash
tui.action.collapse_toggle
```

Collapses or expands the nearest collapsible pane around the focus (default key `alt+c`).

**Returns:** `1` when no collapsible pane encloses the focus.

**Notes**

- After a collapse the keyboard pane stays on the collapsed pane, so the same key opens it again.

**See also:** [`tui.collapse`](/api/core/tui.collapse.html)
