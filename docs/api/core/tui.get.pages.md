### `tui.get.pages`

```bash
tui.get.pages
```

Prints the pages linked by a `<button page="…">` so far, sorted, one per line as `PAGE<TAB>TITLE`.

**Notes**

- `PAGE` is the path as written in the `page` attribute; `TITLE` is the button caption.
- The command palette uses this list to offer page commands.
