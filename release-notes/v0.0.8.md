DABT can now package an app into one signed `.dapk` file, verify it on install, and release it from GitHub Actions. DABT itself is now built and released the same way.

<h2><img src="https://raw.githubusercontent.com/DinosaursAreCute/DinosAmazingBashTui/main/assets/headers/release-new.svg" alt="What's new" height="35"></h2>

- **`dabt build`** packages an app into one signed, reproducible `.dapk`, named `<name>-<version>-<build>.dapk`.
- **`dabt app install`** accepts a `.dapk` (file or URL) or a `.zip` holding one, for example a downloaded workflow artifact. Signature and every checksum are verified before anything is written.
- **Signer trust:** the first install of an app asks whether to trust its signer (pin it with `--trust-key SHA256:...`). A changed signer later is refused.
- **Dependencies:** packages can declare system dependencies. `dabt app install` lists what is missing and installs it only with your consent.
- **News:** `dabt app install` shows what changed since the version you have.
- **`dabt install`** warns when `dabt` is not on your `PATH` and prints the line to add for your shell.
- **Tutorial:** *Writing Your First App* now covers packaging and releasing your own app (steps 9 and 10).

```bash
curl -fsSL https://raw.githubusercontent.com/DinosaursAreCute/DinosAmazingBashTui/main/install.sh | bash   # new install
```

<h2><img src="https://raw.githubusercontent.com/DinosaursAreCute/DinosAmazingBashTui/main/assets/headers/release-package.svg" alt="Package your own app" height="35"></h2>

```bash
dabt build --auto-sign          # creates a signing key once, writes dist/<name>-<version>-<build>.dapk
dabt pkg key                    # the fingerprint your users pin
dabt pkg ci init github         # a workflow that builds, signs and publishes on every v* tag
```

Details: [Packaging and releasing apps](https://dinosaursarecute.github.io/DinosAmazingBashTui/guide/packaging) and the [tutorial](https://dinosaursarecute.github.io/DinosAmazingBashTui/tutorials/writing-your-first-app).

<h2><img src="https://raw.githubusercontent.com/DinosaursAreCute/DinosAmazingBashTui/main/assets/headers/release-added.svg" alt="Added" height="35"></h2>

- **Packaging:** `dabt build [DIR]`, configured by `dabt.pkg` (`include_paths`, `exclude`, `[[include]]`, `[[dependency]]`, `changelog`, `publish_repo`, `sign_key`, `build_offset`, `requires_dabt`). Writes the package, its `.sha256`, `<name>-news.txt`, `RELEASE_NOTES.md` and `dist/build.log`.
- **Signing:** Ed25519 via `ssh-keygen -Y`. Key order: `--key`, then `DABT_SIGN_KEY`, then `sign_key` in `dabt.pkg`, then `~/.config/DABT/keys/dabt_ed25519`. `--auto-sign` creates the default key, `--no-sign` builds unsigned.
- **Versions and build numbers:** the version comes from a CI tag, `VERSION` or `.dabt.metadata`, and `--suffix dev|rc.N` adds a pre-release suffix. The build number follows a dash (`1.2.3-57`, `1.2.3-dev-57`). It comes from `DABT_BUILD_NUMBER`, the CI run counter plus `build_offset`, or the git commit count.
- **`dabt pkg`:** `verify`, `info`, `news`, `version`, `release`, `publish`, `deps`, `include`, `dep`, `key` and `ci init github|gitlab`.
- **Changelog and News:** `### News` bullets are extracted into `NEWS` inside the package and `<name>-news.txt`. Release notes come from a template.
- **Install options:** `--trust-key`, `--allow-unsigned`, `--plan`, `--install-path DIR`, `--install-dependencies`, `--yes`, `--no-deps`, `--require-deps`, `--allow-custom-install`, `--pm NAME`.
- **CI for DABT itself:** the bats suite runs in parallel, DABT is packaged, signed and checked against a pinned fingerprint, and an install plus update from that package is tested before release.
- **Also:** `dabt.pkg` for the framework itself, an MIT `LICENSE`, a Jekyll documentation site, README badges and an "Apps built with D.A.B.T" section, tutorial steps 9 and 10, and bats tests for packaging.

<h2><img src="https://raw.githubusercontent.com/DinosaursAreCute/DinosAmazingBashTui/main/assets/headers/release-changed.svg" alt="Changed" height="35"></h2>

- `dabt` ends its command dispatch with `esac; exit $?` on one line, so `dabt update` can replace `bin/dabt` while it runs. An older `dabt` updating itself to 0.0.8 may print a shell syntax error after the update finished. The update itself succeeds.

<h2><img src="https://raw.githubusercontent.com/DinosaursAreCute/DinosAmazingBashTui/main/assets/headers/release-fixed.svg" alt="Fixed" height="35"></h2>

- Widgets outside their pane's content area are clipped and no longer draw over borders and neighbouring panes (charts and long content).
- The `tui.exec` status line no longer overflows a narrow pane.
- Leaving a page dismisses its running `tui.exec` instances, which fixes a broken control pane on the next page.
