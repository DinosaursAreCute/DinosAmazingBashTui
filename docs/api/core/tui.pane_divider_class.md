### `tui.pane_divider_class`

```bash
tui.pane_divider_class PANE CLASS
```

Sets the theme class that colours the line a fused pane shares with its neighbour.

**Parameters**

- `PANE` - pane id.
- `CLASS` - text, optional. Empty uses the pane's border colour.

**Notes**

- Markup: `divider_class="name"`. Only matters on a fused pane.

**See also:** [`tui.pane_border`](/api/core/tui.pane_border.html)
