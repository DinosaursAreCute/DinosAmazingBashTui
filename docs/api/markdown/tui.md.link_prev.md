### `tui.md.link_prev`

```bash
tui.md.link_prev PANE
```

Focuses the previous link of the document shown in `PANE`, wrapping at the start.

**Notes**

- The document is re-rendered with the focus style (class `link_focus`) and the view scrolls to the link.

**Example**

```bash
tui.md.link_prev docs
```
